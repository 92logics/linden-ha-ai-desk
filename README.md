# Linden Housing Authority desk (prototype)

Scripted sample by [92 Logics](https://www.92logics.com) for the Housing Authority of the City of Linden AI automation, resident communication, and operational support opportunity. It is not the authority’s live system, it is not connected to any resident file, and it is not a bid.

Live page: https://92logics.github.io/linden-ha-ai-desk/

## What it shows

A resident and staff desk. Answers stay inside the public advertisement and the authority pages used for this demo. If those sources disagree, the desk says so.

Portal: https://ha.internationaleprocurement.com

## Run it

Open `index.html` in a browser. No install and no build step.
